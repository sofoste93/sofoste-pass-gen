# Changelog

## 2.0.0 · Aurora Vault — 2026-10-02

- Rebuilt the generator around Java `SecureRandom` and explicit password policies.
- Added a cross-platform Swing desktop interface with English, German and persisted themes.
- Added an installable, offline Progressive Web App for phones and browsers.
- Added Web Crypto generation with rejection sampling, entropy feedback and accessibility controls.
- Added Java and JavaScript security tests, diagnostics and educational comments.
- Added self-contained Windows, Linux and macOS packaging.
- Added illustrated desktop/mobile documentation and a learning guide.
